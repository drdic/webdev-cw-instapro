# Instapro

MVP социальной сети для обмена фотографиями

## Реализованный функционал

- **Лента постов** — отображение всех постов из API с динамической подгрузкой
- **Добавление поста** — авторизованный пользователь может добавить пост с описанием и изображением
- **Страница пользователя** — просмотр постов конкретного автора при клике на его имя
- **Лайки / дизлайки** — авторизованные пользователи могут ставить и снимать лайки без перезагрузки страницы
- **Авторизация и регистрация** — форма входа/регистрации с валидацией, загрузкой аватара и сохранением сессии в localStorage
- **Выход из аккаунта** — кнопка «Выйти» в шапке для авторизованных пользователей
- **Защита от XSS** — HTML-теги в описании поста отображаются как текст (экранирование через `escapeHtml`)
- **Адаптивная вёрстка** — интерфейс корректно отображается на мобильных устройствах (использован Bootstrap)

## Первоначальная оценка

20 часов

## Фактически затраченное время

14 часов

## Дополнительные фичи

- **Bootstrap 5** — все компоненты переведены на Bootstrap-классы (cards, buttons, forms, grid), что улучшило внешний вид и адаптивность
- **Изображения без обрезки** — фотографии в постах отображаются полностью, с сохранением пропорций (использован `img-fluid`, убраны фиксированные высота и `object-fit: cover`)
- **Оптимизация лайков** — переключение лайка выполняется за один запрос к API без повторной загрузки всей ленты
- **Чистка кода** — удалены устаревшие комментарии, JSDoc, неиспользуемые стили; код приведён к единому стилю
- **Спиннер загрузки** — заменён на Bootstrap spinner
